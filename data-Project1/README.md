# 当代人工智能实验一：文本分类

## 运行方式
1. 安装依赖：`pip install scikit-learn pandas numpy matplotlib nltk`
2. 运行：`python draft_main.py`

## 数据集
- train_data.csv：带标签训练集
- test_data_unlabeled.csv：无标签测试集

## 文件说明
- draft_main.py：主实验代码
- val_result.csv：各模型验证集结果
- loss_report.png：MLP 训练/验证损失曲线
- confusion_matrix.png：混淆矩阵
- class_report.txt：分类报告
- exp_log.json：实验元信息
